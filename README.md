JavaScript Array Operations

About

This is a simple JavaScript project. I made this project to practice working with arrays, functions, function expressions, arrow functions, loops, and conditional statements in JavaScript.

The program performs different operations on an array such as finding the maximum number, calculating the sum of all numbers, and counting the total number of odd numbers.

Technologies Used

JavaScript

Features

Finds the maximum number from an array

Calculates the sum of all numbers in an array

Counts the total number of odd numbers in an array

Uses different types of functions

Displays the results using console.log()

Operations Performed

1. Maximum Number

Finds the maximum number from the given array using a function and for loop.

2. Sum of All Numbers

Calculates the sum of all numbers in the given array using a function expression.

3. Count Odd Numbers

Checks the numbers in the array and counts how many numbers are odd using an arrow function.

How to Run
